# מדריך חנויות בקניונים — הדר ירושלים + סביונים יהוד

מנוע שאוסף אוטומטית את רשימת החנויות והקומות מהאתרים הרשמיים של הקניונים, וממשק חיפוש
שאפשר להטמיע באתר שלך. המנוע מתעדכן לבד **כל יומיים** דרך GitHub Actions — בחינם, בלי שרת.

## מה יש בחבילה

| קובץ | תפקיד |
|------|-------|
| `index.html` | ממשק החיפוש — תיבת חיפוש, תוצאות עם שם/תמונה/קניון, ולחיצה שפותחת את כל הפרטים (קומה, טלפון, שעות). |
| `stores.json` | קובץ הנתונים שהממשק קורא. כרגע מכיל **נתונים אמיתיים** שנאספו כבר (155 חנויות), כדי שהכול יעבוד מיד. |
| `scraper.py` | המנוע — סורק את שני האתרים ומעדכן את `stores.json`. |
| `data/savyonim_floors.json` | מיפוי הקומות של סביונים (האתר הרשמי לא מפרסם קומות — ראו הערה למטה). |
| `.github/workflows/update.yml` | ההרצה האוטומטית כל יומיים. |
| `build_seed.py` | הסקריפט שבנה את הנתונים ההתחלתיים (לא נדרש להרצה שוטפת). |

## הפעלה מהירה (מקומית)
```bash
pip install requests beautifulsoup4 lxml
python3 scraper.py          # מעדכן את stores.json
python3 -m http.server 8000 # ואז פותחים http://localhost:8000
```
> חשוב: פותחים דרך שרת (http), לא בלחיצה כפולה על הקובץ — דפדפנים חוסמים טעינת JSON מקובץ מקומי.

## העלאה לאוויר + עדכון אוטומטי כל יומיים (GitHub Pages)
1. פותחים ריפו חדש ב-GitHub ומעלים את כל הקבצים האלה.
2. Settings → Pages → Source: `Deploy from a branch` → `main` / root. האתר יעלה בכתובת `https://<user>.github.io/<repo>/`.
3. זהו. הקובץ `.github/workflows/update.yml` כבר מגדיר עדכון כל יומיים. אפשר גם להריץ ידנית: לשונית **Actions** → *עדכון חנויות קניונים* → **Run workflow**.

## איך מטמיעים באתר שלך
כשיהיה לך אתר, יש שתי דרכים:

**א׳ — iframe (הכי פשוט, עובד בכל פלטפורמה כולל Wix/וורדפרס):**
```html
<iframe src="https://<user>.github.io/<repo>/" style="width:100%;height:700px;border:0"></iframe>
```

**ב׳ — הטמעה ישירה:** מעתיקים את `index.html` ו-`stores.json` לאתר. אם ה-JSON נמצא בכתובת אחרת,
פותחים את `index.html` ומשנים בראש ה-`<script>` את השורה:
```js
const DATA_URL = "https://<user>.github.io/<repo>/stores.json";
```

## הערה חשובה על קומות בסביונים
האתר הרשמי של **קניון סביונים אינו מפרסם קומה** לכל חנות. לכן הקומות נלקחות מהקובץ
`data/savyonim_floors.json` (נבנה מהרשימה שסיפקת). המנוע מצליב בכל ריצה שם חנות → קומה.
כשנפתחת חנות חדשה בסביונים, המנוע יזהה אותה אוטומטית אבל הקומה שלה תופיע "לא ידוע" עד
שתוסיף אותה לקובץ הזה — פשוט מוסיפים שורה: `"שם החנות": "קומה 2"`.
בקניון הדר הקומות נאספות אוטומטית מהאתר, כולל חנויות חדשות.

## עמידות
המנוע ממזג עם הנתונים הקיימים: אם סריקה של קניון נכשלת או מחזירה מעט מדי חנויות, הוא
**שומר את הנתונים הקודמים** של אותו קניון כך שהאתר לעולם לא נשאר ריק. כל ריצה מדפיסה
סיכום: אילו חנויות נוספו, הוסרו, או שינו קומה.
